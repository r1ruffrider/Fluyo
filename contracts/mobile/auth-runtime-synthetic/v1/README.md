# Native auth synthetic kernel contract v1

This directory defines the repository-only, provider-neutral corpus for `AUTH-RUNTIME-SYNTHETIC-KERNEL-V1`. It is test input, is not copied into either application artifact, performs no provider or network request, and increments live runtime evidence by zero. All fourteen live-auth decisions remain open, all 69 readiness requirements remain unsatisfied, and all 24 mirrored live rows remain unattempted.

`vectors.tsv` is the only corpus. It is strict UTF-8 without a byte-order mark, uses LF line endings, has one header plus exactly 28 existing synthetic scenario rows and 13 existing invariant rows, and contains only closed identifiers, enums, booleans, integers, and the auth-state bundle digest. Each row declares ordered inputs, nondecreasing injected monotonic times, typed port commands that select fake return and suspension behavior, every published snapshot in order, the exact one-record-per-transition aggregate presentation-effect FIFO, ordered normalized traces, wipe order, and rejected-write count. The corpus covers initialization immediately before, at, and after the 500 ms announcement boundary. OAuth state and the opaque PKCE verifier are independent bindings. The bundle digest is SHA-256 over `README.md`, `acceptance.json`, `copy.json`, and `state-machine.json` from `contracts/mobile/auth-state/v1`, sorted by filename and framed as UTF-8 filename, NUL, big-endian 32-bit byte length, then raw file bytes.

Swift and Kotlin unit tests read these exact bytes from the checkout, drive the real coordinator through scriptable test-only ports, and compare normalized snapshot, presentation-effect FIFO, generation, trace, wipe, and rejected-write outputs. The corpus is deliberately absent from native resource build phases and Android source-set resources.

Actual screen-reader delivery, spoken output, 200% rendering, touch geometry, contrast, reduced-motion rendering, orientation and resize behavior, browser or OS-link delivery, and screenshots are `not_applicable_kernel_only` and excluded from synthetic-kernel PASS denominators.
